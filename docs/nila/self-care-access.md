# Nila self-care access

Mood tracking, written journals, calendars, self-care activities, challenge progress and recaps can be used without Twilio, a destination phone number, provider keys or a provider upgrade. Deepgram and ElevenLabs connections remain optional and encrypted per customer. Their credits, trial duration and usage limits are independent of access to Nila's manual features.

On the onboarding page, confirm adult eligibility and choose **Use mood tracking without calls**. The authenticated API transaction records calls and speech processing as declined, disables schedules, cancels queued jobs and marks that user's onboarding complete. It does not remove connected provider keys or modify another user's data. Phone setup can be revisited from onboarding or Settings.

The telephone pipeline remains separately gated by provider capability, verified destination, language/voice preferences, explicit consent and platform availability. Self-care access cannot grant permission to place calls. The dashboard offers optional call setup instead of an enabled call button when these requirements are missing.

The earlier terminal prototype has a Gather mode in `buddy/phone.py`, `buddy/deepgram_ai.py` and `buddy/voice_audio.py`. That mode receives Twilio speech results in webhook requests and uses Deepgram to interpret answers and ElevenLabs to produce playback. It is distinct from the deployed Python SaaS Media Streams bridge. This release preserves that prototype; it does not claim that Gather has been migrated or verified for multi-user cloud calls. A migration needs durable per-call turn state, private playback authorization, trial webhook authentication tests, bounded URL hops, idempotent answer processing, recipient verification and the journal approval flow.

Twilio's current [Voice trial documentation](https://www.twilio.com/docs/usage/trials/try-out-voice) allows Gather and Play with restrictions but blocks Stream. The supplied speech-recognition template runs Twilio's demo. From and To numbers select endpoints; they do not configure Deepgram, ElevenLabs or Nila's signed webhook. Trial numbers may vary by product and recipient. [Trial accounts](https://www.twilio.com/docs/usage/trials) expire after 30 days; changing caller numbers is not a documented way to renew trial eligibility.

Deploy the backend first: Render API service, branch `codex/nila-platform`, latest commit. Then approve and publish the matching website changes to the Nila repository's production branch. The voice service does not need a deployment for this release, and no database schema migration or credential changes are required. After publication, sign in, finish self-care onboarding, save a mood, write a journal and confirm persistence after reloading. A real account acceptance test remains necessary after deployment.
